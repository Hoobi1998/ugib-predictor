ECG Heartbeat Classification 1D-CNN
סקירה Pipeline Quick Start מה מקבלים

Machine Learning Project

סיווג פעימות ECG פתולוגיות באמצעות 1D-CNN ולמידת העברה

הפרויקט מאמן מודל כללי על MIT-BIH, ממשיך ל־fine-tuning לפי מטופל, ומשווה מול baseline שמאומן מאפס לכל מטופל. המטרה: להעריך האם ידע מקדים משפר דיוק בזיהוי פעימות חריגות.

הרצה מהירה תיעוד מקומי
MIT-BIH מאגר קלאסי לאנליזת אריתמיה לפי מטופלים.
PyTorch אימון 1D-CNN ו־fine-tuning לכל מטופל.
3 מצבים pre-training, individuals, fine_tuning
Smoke Test בדיקת תקינות מהירה עם epoch אחד על מטופל 100.

מה יש בפנים

ארכיטקטורה תפעולית שמפרידה בין pre-training כללי, baseline פר־מטופל, ו־fine-tuning. התהליך מאפשר השוואה שקופה בין אימון מאפס לבין transfer learning.

Pre-training

אימון מודל גנרי על סט רחב של מטופלים כדי ללמוד ייצוג ECG בסיסי.

Baseline Individuals

אימון עצמאי לכל מטופל מאפס, לצורך קו בסיס הוגן להשוואה.

Fine-tuning

טעינת checkpoint מאומן והתאמה ממוקדת למטופל יעד.

Pipeline בפשטות

הזרימה מסוף־לסוף מהרצת נתונים ועד checkpoints לכל מטופל.

שלב 1

Dataset

קריאת קבצי MIT-BIH מתוך dataset/mitbih_database.

שלב 2

Windowing + Split

עיבוד פעימות, חלוקה ל־train/val/test ושקלול דגימות לפי הצורך.

שלב 3

Training Mode

בחירה ב־--state להפעלת pre-training / baseline / fine-tuning.

שלב 4

Outputs

שמירת checkpoints ולוגים תחת נתיב פלט לבחירתך.

Quick Start

פקודות קצרות להתחלה מהירה בפיתוח מקומי ובדיקת תקינות.

Terminal setup + smoke 
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip wheel
python -m pip install -r requirements-local.txt
python run_smoke_test.py

Pre-training

python src/main.py --state pre-training --output_path ./output/

Baseline למטופל

python src/main.py --state individuals --selected_patients_fine_tuning 100 --output_path ./output/

Fine-tuning

python src/main.py --state fine_tuning --pretrain_path ./output/save_16.pth --selected_patients_fine_tuning 100 --output_path ./output/

למי זה מתאים?

לקורסים ב־ML, לניסויי transfer learning ב־ECG, ולצוותים שרוצים בסיס נקי להשוואות בין אימון מאפס להתאמה פר־מטופל.
